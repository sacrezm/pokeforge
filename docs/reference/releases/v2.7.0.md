## New

**PokéForge for Codex** — open your companion, owned Pokémon collection, training,
AI usage and token shop in a Codex extension panel. It connects to the PokéForge
engine bundled with the plugin, including existing Pokémon and trading inventory.
No separate Mac app installation or menu-bar icon is required.
Catch, Train and Balanced use the same native progression and save. Trading and
advanced settings open in an on-demand window.

**Native app improvements from PokeTokenBar upstream:**

- Usage recaps for any week, month or year, monthly daily trends, and quota pacing
  indicators ([#332](https://github.com/chattymin/PokeTokenBar/pull/332),
  [#270](https://github.com/chattymin/PokeTokenBar/pull/270),
  [#349](https://github.com/chattymin/PokeTokenBar/pull/349)).
- Automatic local save backups, corruption recovery and restore controls
  ([#330](https://github.com/chattymin/PokeTokenBar/pull/330)).
- Multiple Claude accounts with separate session keys, Cursor included-usage
  limits, and Aside usage tracking
  ([#327](https://github.com/chattymin/PokeTokenBar/pull/327),
  [#346](https://github.com/chattymin/PokeTokenBar/pull/346),
  [#273](https://github.com/chattymin/PokeTokenBar/pull/273),
  [#283](https://github.com/chattymin/PokeTokenBar/pull/283)).
- Persistent individual Pokémon details, collectible Unown forms, bulk Rare Candy
  previews, and collection search, sorting and filters
  ([#264](https://github.com/chattymin/PokeTokenBar/pull/264),
  [#288](https://github.com/chattymin/PokeTokenBar/pull/288),
  [#328](https://github.com/chattymin/PokeTokenBar/pull/328),
  [#329](https://github.com/chattymin/PokeTokenBar/pull/329)).

## Fixed

- Usage pace markers match the native progress-bar height on older macOS versions.
- Plugin actions use the native save writer, check purchase prices and ownership,
  roll back failed saves, and prevent duplicate spending from a repeated request.
  Lost responses are reported without automatically retrying the purchase.
- Codex discovery recognizes the CLI nested in the ChatGPT app; OpenCode v2 usage
  messages are readable
  ([#369](https://github.com/chattymin/PokeTokenBar/pull/369),
  [#363](https://github.com/chattymin/PokeTokenBar/pull/363)).
- Claude forked usage stays with its original account, cost displays distinguish
  estimates from unavailable values, and additional model prices are recognized
  ([#344](https://github.com/chattymin/PokeTokenBar/pull/344),
  [#289](https://github.com/chattymin/PokeTokenBar/pull/289),
  [#354](https://github.com/chattymin/PokeTokenBar/pull/354)).
- Rare Candy grants reset with their usage window, legendary companions receive
  an extra discard safeguard, and large collection views are easier to browse
  ([#334](https://github.com/chattymin/PokeTokenBar/pull/334),
  [#335](https://github.com/chattymin/PokeTokenBar/pull/335),
  [#370](https://github.com/chattymin/PokeTokenBar/pull/370)).

  using the developer's login; unchanged poll results no longer flood logs

  [#355](https://github.com/chattymin/PokeTokenBar/pull/355),

## Other

- One public name: **PokéForge**, with plugin identifier `pokeforge`. Existing app,
  save, Keychain and trading identities remain compatible.
- The plugin is available through this repository's Codex marketplace and as a
  ready-to-install ZIP, including icons and bundled dependency licenses. No npm
  build, API key or second save is required to install it.
- Release assets include a universal Apple Silicon + Intel Mac app, the plugin
  marketplace ZIP, a signed Sparkle update feed and SHA-256 checksums. The app uses
  the existing signing identity; it is self-signed, not Apple-notarized.
- PokéForge remains an independently maintained, unofficial Pokémon fan fork of
  [PokeTokenBar](https://github.com/chattymin/PokeTokenBar). Trainer battles and
  exploration remain future work. The new plugin interface is in English.

**Install:** Requires macOS 14 or newer. Download `PokeForge-v2.7.0.zip`, unzip it,
move `PokeForge.app` to `/Applications` and open it. macOS may require approval in
Privacy & Security for this self-signed app.

**Codex plugin:** With Node.js 24+ installed and a Codex desktop client supporting
plugin extensions, run:

```sh
codex plugin marketplace add sacrezm/pokeforge
codex plugin add pokeforge@pokeforge
```

Start a new Codex chat and ask **Open PokéForge**. Alternatively, extract
`PokeForge-Codex-v2.7.0.zip` and add that extracted directory with
`codex plugin marketplace add /absolute/path/to/PokeForge-Codex-v2.7.0` before
installing `pokeforge@pokeforge`. The plugin includes a local Mac engine; it does not
run against a cloud Codex environment. Existing compatible desktop apps are reused
when running. Quit older apps before using the standalone plugin.

**Upgrade:** Current PokéForge users can use **Update & Restart**. Pre-PokéForge
builds need a manual installation: turn off Launch at login in the old app, quit
it, install the new app, verify your collection and re-enable Launch at login.
Existing saves and trainer credentials are retained. Avoid running both apps
against the same save. Git-installed plugins can be updated with
`codex plugin marketplace upgrade pokeforge` followed by
`codex plugin add pokeforge@pokeforge`.
